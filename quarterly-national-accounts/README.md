# A-CLUSTER Quarterly National Accounts

Publication namespace for the A-CLUSTER Quarterly National Accounts structural macro monitor.

## Structure

- `index.html` — country landing page
- `greece/index.html` — latest Greece report (stable URL)
- `greece/archive/` — quarter-specific historical reports
- future countries follow the same pattern, e.g. `italy/`, `germany/`, `france/`

The analytical pipeline is country-aware. Each country keeps a stable latest-report URL while historical quarterly reports are archived separately.
